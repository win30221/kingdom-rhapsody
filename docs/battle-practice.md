# 王國狂想對戰

以 Unity `6000.6.8f1` 開啟完整倉庫中的 `unity/`，播放 `Assets/Scenes/Lobby.unity`。配置左右護衛及八張牌後按「出戰」，再選擇「本機對練」或「雙人對戰」。

開兩個連向同一個服務的客戶端，分別點「雙人對戰」即可配對。WebGL 預設連遊戲頁面的同一個來源，桌面版預設連本機服務。兩端可使用不同牌組和護衛配置。開場後兩邊都從己方在下的視角操作。雙人對戰中的離開選單不會暫停比賽，任一方在比賽中離開會判負。結算後可再次配對。[Go 服務設定](../server/README.md)

## 操作

- 點手牌再點戰場，或直接拖手牌至部署格。不同手牌可同時拖曳，各指使用各自的目標與預覽。
- 開局整座己方石地庭院都能下兵。部隊由三座橋過河，靠岸部署點會依碰撞尺寸留在石地上。
- 青色格代表己方部署權，琥珀色格代表雙方都可部署。同格第一筆合法命令先佔用，另一筆會被拒絕並保留手牌和能量。
- 裂地波動可先選牌，再在戰場按下起點並拖曳決定方向。也可直接從手牌拖入戰場 鎖定 起點，再改變指標方向。方向線與實際命中範圍一致。
- 王子疾行消耗 2 點能量，加速 3 秒，從啟動起算冷卻 15 秒。能量不足、冷卻或受暈時，疾行按鈕不可用。

## 規則

- 對戰兩秒倒數後開始，正賽 180 秒。若兩位王子都存活，自動進入 60 秒延長賽。正賽每 3 秒回 1 點能量，延長賽回復速度暫定為 2 倍。起始能量 5，上限 10。
- 任一王子死亡當 tick 判定勝負，兩位王子同 tick 死亡為平手。240 秒時兩位仍存活，才比較剩餘血量。同 tick 已成立的命中會先收集再結算，角色建立順序不會取消對方該 tick 的反擊。
- 三路戰場、王子路線與護衛部署解鎖參照[戰場規格](battle-map-design.md)。護衛以原駐點的碰撞邊界偵測，並在固定追擊半徑內接敵，離戰後回原位。
- 卡牌數值採[初始設定 V0.1](card-balance-v0.1.md)。近戰命中幀重查距離，遠程於出手幀發射，到達才改變 HP、護盾或狀態。醫官藥瓶到達後才治療。巨斧只在扇形真的打到時產生命中演出。
- 法術以世界座標判定。無施法延遲的法術會在下一個共同模擬 tick 套用，隕星仍保留 1 秒預警。中央裂痕每 8 秒爆發。中毒無視護盾，暈眩結束後有 0.6 秒抗暈時間。

## 呈現

- [GameNetKit](https://github.com/win30221/gamenetkit/tree/8e923249f68d71a343a3224200494603ed8712ea) 的 Core、Interpolation、Replication 和 Transport 封裝在 `unity/Packages/`。畫面使用 30 Hz 模擬及 15 Hz 例行快照。傷害和狀態切換會追加同 tick 快照，讓畫面上的王子 HP、場上血條、部署權與特效使用同一個呈現時間。
- 晶甲犰狳無盾時維持暗色，回盾幀與盾值同步。赤翼蝠獸在嗜血期間有紅色外觀和持續標記。中毒、減速、暈眩與軍旗增益都有戰場標記。結算前會先播完最後命中與退場。
- 前景的法術和投射物由遊戲繪製，主要事件有短音效並共用大廳靜音設定。戰場版面盡量使用直式安全區高度，過窄時只裁左右邊緣，保留最外側格子的中心與操作區。
- 移動循環隨實際位移取樣，每次顯示一張精靈圖。六個異獸的移動動畫在匯入時為重複影格補上中間姿勢，保留原始關鍵姿勢、錨點、每秒格數與出手點。其餘同圖影格共用貼圖格。花妖和弩手的指定邊緣修正也在匯入時套用。更新素材或配置後執行 `python3 tools/sync_battle_actors.py`。[動畫設定](../art/character-sprites/animation-roster.json)
- `python3 tools/Prepare-BattleSounds.py` 可重建戰鬥 WAV，`python3 tools/Prepare-LobbyFont.py` 可更新新文案的繁中字型子集。

## 從稽核到修正

| 稽核項目 | 修正及驗證方式 |
| --- | --- |
| 本機 AI 之外缺兩人連線 | Go 配對兩個客戶端，後端執行同一套戰鬥模擬，分別下發私有手牌和共用戰場。Go 整合測試走實際 WebSocket 與正式 .NET 工作程序。 |
| 時限、疾行扣費、同 tick 交換傷害 | .NET 回歸覆蓋 180→240 秒、雙倍回能、扣費拒絕、同時互砍、雙王子同 tick 死亡和平手。 |
| 護衛索敵、醫官跟隨、軍旗半徑、巨斧扇形 | .NET 回歸覆蓋兩種護衛邊界、醫官等待與治療、旗手實際範圍、巨斧揮空及同格佔用。 |
| 出手與命中、血條、狀態、最後一擊 | .NET 回歸覆蓋投射物飛抵前後、同 tick 快照、破盾與覺醒被暈、回盾幀以及呈現尾段。角色退場、音效與手機畫面需在 Unity 播放檢查。 |
| 裂地、並行拖牌、窄螢幕與素材 | 程式已分開各指標狀態、整合兩種裂地手勢並保留邊緣可操作範圍。影格共用與遮罩可離線核對。手勢、角色補間觀感與效能需用 Unity 和目標裝置確認。 |

從倉庫根目錄執行戰鬥規則回歸。

```sh
dotnet run --project tools/battle-smoke/BattleSmoke.csproj
```

這組 .NET 測試也涵蓋裂地移出場外取消、棄權時的同 tick 終局、不同到包順序的能量預扣，以及目標提前死亡時的火炮與火焰爆炸中心。

從倉庫根目錄用 Node.js 22 以上版本執行 WebGL 橋接回歸。

```sh
node --test tools/battle-smoke/webgl-transport.test.mjs
```

橋接測試模擬 8 秒未取包，確認恢復時使用最新狀態，終局和命令回覆會依序送給 Unity。上線前仍需在 Unity WebGL 成品測試實際切換分頁。

第一次在 Unity 驗收時，用兩個客戶端完成一局，並分別測左右護衛、重疊格、四指手勢與裂地方向。手機 9:16 和 9:20 都測最外側格。錄下弩手命中、犰狳無盾五秒、蝠獸嗜血和結算前的退場，並量測第一次進場與再戰的幀時間和貼圖記憶體。
