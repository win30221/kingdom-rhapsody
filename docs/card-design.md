# 《王國狂想》卡牌與戰鬥定位設計

更新日期：2026-11-27

本文件整理初期 20 張可出戰卡牌，以及王子與固定護衛的戰術定位，供後續美術、Unity 大廳卡牌資訊、戰鬥系統及數值平衡使用。這是設計規格，不代表戰鬥功能已實作。

## 1. 設計範圍與狀態

- 初期卡池：11 種既有人類兵種、6 種新增異獸、3 種法術，共 20 張。
- 玩家出戰牌組維持 8 張。王子及左右兩名固定護衛不占卡牌格；護衛各自可選擇長槍兵或弩手。
- DEMO 收藏卡只用於 UI 測試，不列入正式卡池。
- **已定案**：第 12–17 張的核心機制、第 19 張的百分比範圍傷害、第 20 張的固定直線傷害。
- **初步方向**：原有 11 種兵種的戰鬥特性、護衛定位，以及第 18 張隕星墜落的具體規則。人類兵種尚未逐一正式確認。
- **數值待平衡**：血量、傷害、攻速、移速、射程、召喚／施法成本、爆擊倍率、護盾量、時間、範圍、法術對王子的傷害等。雷霆裁決的 20% 與王子 1% 是已討論的初始測試值，而非最終平衡承諾。
- 現行大廳資料來源：[LobbyLoadout.cs](../unity/Assets/Lobby/Scripts/LobbyLoadout.cs)。目前 Roster.Troops 有 11 個正式 ID；新卡的 ID 在本文件中僅為建議，尚未登錄。法術尚未接入正式卡牌資料及戰鬥流程。

## 2. 共同設計原則

1. 每張卡牌應有清楚的戰術價值，但不必每張都具備獨立技能。一般兵種以數值、成本、攻擊形狀或支援行為取得優勢；特殊兵種才使用觸發計數、狀態切換等機制。
2. 基礎型、特性型、機制型是理解複雜度的分類，不是強度或稀有度等級。不能因為異獸有技能，就讓異獸全面取代人類兵種。
3. 同一張卡盡量只承擔一種核心特色；不隨意疊加回血、護盾、控制、穿盾與爆發等優勢。
4. 低成本兵種同樣要有出戰價值。以相同資源下的有效輸出、生存時間、接敵時間、攻擊覆蓋率和克制關係做比較，不以單張滿級數值判斷強弱。
5. 固定護衛是王子的長期戰鬥夥伴，應有穩定的泛用性，不應因射程設定而被一般遠程兵種無傷消耗。召喚兵種可有更鮮明的優缺點。
6. 法術初期以直覺的攻擊效果為主：固定圓形傷害、百分比圓形傷害、固定直線傷害。不引入實體牆或複雜的控制、增益及淨化系統。
7. 法術可以影響王子，但不應取代部隊交戰成為主要勝負手段。王子需有獨立的傷害規則；不將一般兵種的百分比傷害原樣套用。

## 3. 固定班底（不計入 20 張卡牌）

| 皇家護衛長槍兵 | 近戰護衛 | 較長的近戰攻擊距離，攔截接近王子的敵軍 | 初步方向 |

### 3.1 皇家護衛弩手與新手弓手

| 屬性 | 新手弓手（召喚兵種） | 皇家護衛弩手（固定護衛） |
| --- | --- | --- |
| 射程 | 遠 | 遠；與新手弓手採相同基準 |
| 單次傷害 | 較低 | 較高 |
| 攻擊速度 | 較快 | 較慢 |
| 血量 | 低 | 中等偏高 |
| 攻擊目標 | 單體 | 單體 |
| 戰術價值 | 持續輸出、清理低血量敵人，減少過量傷害 | 穩定後方火力、單次高傷害 |
| 獨立被動技能 | 不需要 | 不需要 |

**射程原則：** 不讓新手弓手單靠射程就站在弩手的攻擊範圍外持續白嫖護衛血量。兩者使用相同射程基準，而非要求弩手全面優於弓手。這是遊戲平衡決策，不以真實武器史作為強制規則。未來如果新增超遠程角色，需另行考慮反制方式及代價。

弩手曾討論過護甲穿透或額外護盾傷害，但目前不納入技能，避免增加不必要的系統。護衛的實際接敵、追擊距離與攻擊判定仍需在戰鬥實作中驗證。

## 5. 既有人類兵種（初步規格）

本節的定位、相對數值與能力是討論方向，不視為已實作或不可修改的正式設定。沒有額外被動並非缺陷。

### 01. 盾兵

- **定位：** 穩定前排、承受傷害。
- **數值方向：** 高基礎血量、低攻擊力、偏慢移速與攻速；近戰單體。
- **能力：** 以盾擊進行普通攻擊。暫以高血量作為生存優勢，不強制加入正面減傷、額外護盾或再生。
- **優勢：** 不依賴觸發條件即可扛傷；較不受穿盾毒傷的特殊克制。
- **弱點：** 輸出低，容易被裂甲穿山獸及百分比傷害法術有效消耗。
- **與晶甲犰狳區分：** 盾兵基礎血量較高；犰狳依靠可再生的護盾，適合間歇性戰鬥。

### 02. 新手弓手

- **定位：** 基礎遠程單體持續輸出。
- **數值方向：** 低血量、較低單次傷害、較快攻速、遠射程。
- **能力：** 普通射箭，不增加獨立技能。
- **優勢：** 適合搭配前排，持續輸出並清理低血量敵人。
- **弱點：** 遭近戰貼身或範圍攻擊時較脆弱。
- **射程：** 與皇家護衛弩手相同。詳見第 3.1 節。

### 03. 火炮槍兵

- **定位：** 遠程範圍輸出。
- **數值方向：** 偏高單次傷害、較慢攻速，射程及血量待平衡。
- **能力：** 發射炮彈，命中目標時對爆炸範圍內敵人造成傷害；不另外附帶暈眩或擊退。
- **優勢：** 克制聚集的小兵、密集陣線。
- **弱點：** 對分散敵人時範圍效益低；慢速攻擊可能造成過量傷害。
- **與火焰術士區分：** 火炮以炮彈爆炸及較重的單次攻擊為方向；兩者的射程、爆炸半徑、傷害頻率應於平衡階段拉開差異。

### 04. 近戰小兵

- **定位：** 低成本近戰、補充兵力。
- **數值方向：** 血量及單次傷害較低，召喚成本低。
- **能力：** 短劍單體攻擊，無獨立技能。
- **優勢：** 快速補充陣線、以多個低成本單位牽制敵人；能使高單次傷害或反坦克角色浪費輸出。
- **弱點：** 容易受到範圍傷害清除。不得只因無技能就失去成本效益。

### 05. 重鎚兵

- **定位：** 近戰圓形範圍輸出。
- **數值方向：** 攻擊較重、攻速較慢，生存能力待平衡。
- **能力：** 重鎚砸地，對自身附近的圓形範圍內敵人造成傷害（範圍中心待確認）。
- **優勢：** 適合被多方向敵人包圍時作戰。
- **弱點：** 攻速慢、需要接近敵人。
- **限制：** 目前不額外加入暈眩，以免與雷角犀牛重疊。

### 06. 巨斧兵

- **定位：** 近戰扇形範圍輸出。
- **數值方向：** 中等偏高單次傷害，攻擊頻率及血量待平衡。
- **能力：** 巨斧橫掃，傷害面向前方的扇形區域內敵人。
- **優勢：** 擅長對抗正面並排或聚集的敵方兵團。
- **弱點：** 身後或扇形範圍外的敵人不受波及。
- **與重鎚兵區分：** 以攻擊形狀（正面扇形／周圍圓形）及相對數值區別，不需額外被動。

### 07. 冰霜術士

- **定位：** 遠程減速、延緩敵軍進攻。
- **數值方向：** 中低傷害、偏低血量，射程與攻速待平衡。
- **能力：** 冰霜攻擊附帶減速。移動減速為主要方向；是否同時降低攻速、影響範圍、持續時間及刷新方式待確認。
- **優勢：** 延緩近戰部隊接敵，為己方遠程輸出爭取時間。
- **弱點：** 本身不應同時具有高傷害及硬控制。
- **限制：** 不自動加入冰凍或暈眩等額外效果。

### 08. 火焰術士

- **定位：** 魔法範圍輸出。
- **數值方向：** 以範圍輸出為主，血量、單次傷害、攻速及射程待平衡。
- **能力：** 以火焰法術攻擊範圍內敵人，具體攻擊形狀與作用方式待確認。
- **優勢：** 對聚集敵軍取得較好的總輸出。
- **弱點：** 單體輸出不應全面超過同成本的單體專職兵種。
- **限制：** 燃燒持續傷害曾被提議，但未定案；先保留範圍火焰傷害，不新增燃燒或穿盾規則。

### 09. 軍旗手

- **定位：** 團隊增益支援。
- **數值方向：** 以光環價值而非自身傷害為主要成本依據。
- **能力：** 軍旗提升附近友軍的戰鬥能力；優先考慮攻速增益，具體增益種類、範圍、能否作用於自身與護衛、光環疊加規則待確認。
- **優勢：** 附近友軍越能持續輸出，支援價值越高。
- **弱點：** 缺少友軍時效益低；支援位置及存活時間很重要。
- **限制：** 不同時加入多種攻擊、移動、防禦增益，以免成為所有牌組的必選卡。

### 10. 醫官

- **定位：** 治療支援、延長陣線作戰時間。
- **數值方向：** 治療量、治療頻率、治療範圍及自身生存力待平衡。
- **能力：** 定期治療附近受傷友軍；單次治療目標數、優先順序、王子及護衛的治療資格待確認。
- **優勢：** 維持持續作戰部隊的血量，特別是有機會撐過敵方爆發的前排。
- **弱點：** 無法挽救已被擊殺的單位，面對高爆發輸出時治療可能來不及。
- **限制：** 不額外附加護盾、淨化或復活。

### 11. 輕騎兵

- **定位：** 高速突擊、迅速接敵。
- **數值方向：** 較高移動速度；血量、傷害、攻速與成本待平衡。
- **能力：** 以快速移動及接敵作為主要特色，不必獨立計算衝鋒蓄力或額外衝鋒傷害。
- **優勢：** 縮短移動與接敵時間，對遠程部隊施加壓力。
- **弱點：** 受到減速、暈眩及前排阻擋時，高移速優勢下降。
- **限制：** 不預設穿越前排、鎖定後排或範圍擊退；若要加入需另行討論。

## 6. 新增異獸（核心機制已定案）

### 12. 血棘花妖

- **定位：** 近戰、週期性爆發；單體藤蔓抽擊。
- **數值方向：** 中等血量、中等攻擊力、中等偏快攻速、普通移速。
- **被動「血棘綻放」：** 每第三次成功攻擊必定爆擊。前兩次為一般攻擊，第三次爆擊後重新計數；更換攻擊目標不重置計數，未命中不計入。
- **優勢：** 有明確可預期的爆發節奏。
- **弱點：** 被快速擊殺或控制時，可能來不及完成第三擊。
- **限制：** 採用方案 A，已移除最初討論的回血及溢出護盾能力。
- **美術：** 暗紅花苞、帶刺藤蔓；第三擊時花苞綻放，藤蔓重擊伴隨紅色特效。
- **待平衡：** 爆擊倍率及攻擊數值。

### 13. 晶甲犰狳

- **定位：** 近戰、防禦型坦克；單體撞擊。
- **數值方向：** 基礎血量中等且低於盾兵、低攻擊力、慢攻速、慢移速。
- **被動「晶甲再生」：**
  1. 召喚時獲得固定數值的完整自身護盾。
  2. 護盾完全破碎後才開始計算再生時間。
  3. 時間結束後重新獲得完整護盾。
  4. 未破碎的自身護盾不定期補滿，也不無限累加。
- **優勢：** 在交戰空檔或低壓力環境中取得再次防禦的機會。
- **弱點：** 護盾破碎後有防禦空窗；高爆發與毒素穿盾是重要反制。
- **限制：** 不具備自身回血能力。
- **美術：** 圓滾犰狳、藍紫色晶甲。盾破時結晶暗淡，再生時重新發光。
- **待平衡：** 護盾量及再生時間；外來護盾與自身晶甲的關係留待統一護盾規格。

### 14. 毒囊蟾蜍

- **定位：** 遠程、持續傷害及護盾反制；單體毒液攻擊。
- **數值方向：** 中低血量、低基礎攻擊力、慢攻速、普通移速。
- **攻擊特性「腐蝕毒液」：** 普通攻擊命中時附加中毒；中毒期間每秒扣除固定血量，持續固定秒數。
- **中毒規則：** 不可疊加，重複命中只刷新持續時間；不因持續命中而提高每秒毒傷。毒傷無視護盾、直接扣除本體血量；攻擊的普通傷害仍優先扣護盾。
- **優勢：** 對護盾型角色有明確反制作用，且可以持續消耗敵人。
- **弱點：** 基礎爆發較低，短時間戰鬥難以發揮完整毒傷。
- **美術：** 紫綠色圓胖蟾蜍，背部毒囊、綠色毒液泡泡；中毒目標以可辨識綠色粒子提示。
- **待平衡：** 每秒毒傷與持續時間、多名蟾蜍的同種毒素合併及刷新時的跳傷時鐘（建議統一為同種中毒不疊加，細節待確認）。

### 15. 赤翼蝠獸

- **定位：** 近戰、吸血續航；單體撲咬。
- **數值方向：** 中低血量、中低攻擊力、快攻速、快移速。低空飛行為美術方向，不代表已加入飛行尋路或地面攻擊免疫。
- **被動「嗜血覺醒」：**
  1. 初始為普通狀態，不吸血。
  2. 自身血量低於 50% 時進入嗜血狀態（不是等於 50%）。
  3. 嗜血期間每次攻擊命中恢復固定血量，不按傷害或最大血量比例計算。
  4. 即使回復至 50% 以上，嗜血仍持續；直到滿血才解除。
  5. 之後再次低於 50% 可以重新觸發，沒有技能冷卻時間。
- **優勢：** 面對低輸出敵人時，有機會持續進攻並恢復至滿血。
- **弱點：** 低血量、高爆發或控制可能使其無法繼續攻擊吸血。
- **限制：** 溢出治療不轉化為護盾。吸血以固定恢復量平衡，不用增加冷卻破壞核心玩法。
- **美術：** 暗紫蝠身、赤紅翅膀與尖牙；嗜血期間雙眼與翅膀發紅光。
- **待平衡：** 每次固定回血量、攻速與基礎血量。外部治療達滿血的解除判定建議與自身吸血一致，待確認。

### 16. 雷角犀牛

- **定位：** 近戰、單體控制；撞擊敵人。
- **數值方向：** 中高血量、中低攻擊力、慢攻速、普通移速。
- **攻擊特性「雷霆撞擊」：** 每次普通攻擊命中附帶短暫暈眩；暈眩期間目標不能移動及攻擊，暈眩時間不可累加。
- **優勢：** 干擾關鍵敵人的攻擊節奏，協助友軍輸出。
- **弱點：** 自身攻擊速度較慢，輸出不高，不適合單獨清理大量敵人。
- **限制：** 無蓄能、第三擊計數、範圍暈眩或額外護盾傷害。
- **美術：** 深藍犀牛、黃色雷晶獨角，撞擊時出現電光。
- **待平衡：** 暈眩秒數、攻擊間隔、多名犀牛連續控制的處理（避免永久暈眩）；王子是否承受控制與受控時能否中斷已開始的攻擊待確認。

### 17. 裂甲穿山獸

- **定位：** 近戰、反高血量坦克；單體爪擊。
- **數值方向：** 中等血量、低基礎攻擊力、普通攻速及移速。
- **攻擊特性「裂甲重擊」：** 每次命中額外造成目標最大血量一定百分比的傷害，而非依照剩餘血量計算。基礎傷害與額外傷害均循一般護盾傷害規則。
- **優勢：** 目標最大血量越高，額外傷害越高；適合對付盾兵等高血量前排。
- **弱點：** 基礎攻擊力較低，面對大量低血量兵種時效益有限。
- **限制：** 不穿盾、不削減最大血量、不疊加破甲或降低防禦效果。名稱「裂甲」僅代表攻擊意象，不代表需要護甲系統。
- **美術：** 深褐色鱗甲、厚重身軀與巨大前爪。
- **待平衡：** 額外傷害比例、是否對王子設定獨立比例或上限，後者需避免直接套用一般坦克比例。
- **機制示例（非正式數值）：** 基礎傷害 50、比例 5% 時，最大血量 400 的小兵受 70 傷害，最大血量 2,000 的盾兵受 150 傷害。

## 7. 法術卡

法術為一次施放的戰場效果，不召喚可持續移動的角色。卡圖與 Unity 特效另行製作；不需要一般兵種的待機、移動、普攻動畫。

### 18. 隕星墜落（初步方向）

- **定位：** 圓形範圍固定爆發傷害、清理聚集敵軍。
- **施放：** 指定圓形區域，短暫延遲後隕星落下，對落點範圍內每名敵人各造成一次固定傷害。
- **優勢：** 範圍內敵人越多，總傷害越高；尤其適合低血量小兵。
- **弱點：** 有落下延遲，移動中的敵人可能離開範圍；相對不擅長消耗單一高血量坦克。
- **限制：** 不額外加入燃燒、暈眩或擊退。王子仍可受傷，但傷害需獨立平衡。
- **美術：** 地面落點提示、隕星下墜、岩石碎片與火光。
- **待確認：** 範圍、延遲、固定傷害、王子傷害規則、成本。此卡沿用三法術組合中的原方向，尚未逐項正式確認。

### 19. 雷霆裁決（核心機制已定案）

- **定位：** 圓形範圍百分比傷害、消耗高血量敵軍。
- **施放：** 指定圓形區域，瞬間對每名範圍內敵人各造成一次傷害。
- **初始測試值：** 一般兵種及護衛各承受自身最大血量的 20%；王子承受自身最大血量的約 1%。
- **傷害規則：** 依照各目標的最大血量分別計算，正常優先消耗護盾；不降低血量上限，也不附帶暈眩。
- **優勢：** 目標血量上限越高，絕對傷害越高；不會因玩家缺乏坦克而將一筆固定傷害全部集中在大量小兵身上。
- **弱點：** 無法僅靠單次百分比傷害擊殺滿血的一般兵種，亦不應成為直接消耗王子取得勝利的主要手段。
- **已淘汰方案：** 固定 1,000 點共享傷害額度、依序擊殺及把剩餘傷害傳給下一目標的做法，不再使用。
- **美術：** 同一瞬間多道雷電落在命中目標，不需逐一彈射。
- **待平衡：** 百分比、範圍及施法成本；檢查在整場戰鬥中可施放次數對王子的累積影響。

### 20. 裂地波動（核心機制已定案）

- **定位：** 長條直線固定傷害，懲罰縱向排列的敵方部隊。
- **施放：** 指定位置及方向，在直線範圍內造成傷害。
- **傷害規則：** 每名被命中的敵人受到一次相同的固定傷害，不因前方敵人、命中數量或距離而降低／提高傷害。
- **優勢：** 選擇合適施放角度，可同時傷害敵方前後排。
- **弱點：** 橫向分散或不在長條範圍內的敵軍不受影響。
- **限制：** 純直線傷害，不附加擊退、暈眩、減速、地形碰撞或持續傷害；不強制要求以移動中的投射物實現。王子傷害另行設定。
- **美術：** 直線地面裂痕、岩石碎片飛濺；裂痕僅為視覺效果，不改變尋路。
- **待平衡：** 長度、寬度、傷害、施放表現與判定時機、王子傷害及成本。

### 7.1 三張法術分工

| 法術 | 範圍 | 傷害機制 | 主要用途 |
| --- | --- | --- | --- |
| 隕星墜落 | 圓形 | 延遲後固定傷害 | 清理聚集的低血量兵種 |
| 雷霆裁決 | 圓形 | 瞬間按目標最大血量計算 | 消耗高血量兵種 |
| 裂地波動 | 長條直線 | 固定傷害，各命中一次 | 利用角度貫穿前後排 |

岩石壁壘及實體障礙物方案已取消：避免阻擋王子、護衛與友軍，或引入不必要的碰撞與尋路問題。這一版不包含逆風震波、生命崩解等其他候選法術。

## 8. 跨卡牌規則與克制關係

以下規則用於保持實作一致，未確認的部分不應直接當成已定案需求。

### 8.1 傷害及狀態

| 規則 | 目前設計 |
| --- | --- |
| 一般傷害 | 優先消耗護盾，超出部分扣本體血量 |
| 毒素 | 唯一目前明確設計成穿盾的傷害；不扣護盾，直接扣血 |
| 百分比傷害 | 以目標最大血量計算，不改變血量上限，除毒素以外沒有穿盾特性 |
| 護盾再生 | 晶甲犰狳的自身護盾完全破碎才開始再生計時 |
| 治療 | 不超過最大血量；目前沒有溢出轉盾的角色 |
| 爆擊 | 血棘花妖每第三次成功攻擊觸發；不引入通用隨機爆擊規則，除非另行定案 |
| 暈眩 | 不能移動及攻擊，時間不可累加；刷新、控制抗性及王子適用性待確認 |
| 減速 | 冰霜術士以減速為方向；具體屬性與疊加規則待確認 |
| 攻擊目標 | 先維持一致的基礎目標選擇方式；本輪未採用低血量優先、強制鎖後排等特殊索敵能力 |

### 8.2 戰術對照

| 需要處理的情境 | 可考慮的卡牌 | 設計理由 |
| --- | --- | --- |
| 高基礎血量前排 | 裂甲穿山獸、雷霆裁決 | 最大血量百分比傷害 |
| 再生護盾 | 毒囊蟾蜍、集中火力 | 毒傷穿盾；護盾破碎後有再生空窗 |
| 密集小兵 | 火炮槍兵、重鎚兵、巨斧兵、火焰術士、隕星墜落 | 範圍攻擊的總傷害較高 |
| 縱向前後排 | 裂地波動 | 直線傷害不被第一名敵人吸收 |
| 高攻速／吸血角色 | 雷角犀牛、集中爆發 | 暈眩或擊殺可使其失去攻擊機會 |
| 敵方高速推進 | 冰霜術士、前排兵種 | 延緩接敵、維持陣線 |
| 高單次傷害、百分比單體傷害 | 低成本近戰小兵、分散部署 | 讓專職反坦克輸出較難取得完整價值 |
| 遠程消耗 | 輕騎兵、己方遠程、前排掩護 | 快速接敵或反擊；弓手與護衛弩手保持同射程基準 |

以上為預期戰術關係，不保證一對一必勝；仍需依成本、部署位置、部隊數量與實測結果調整。尤其法術不應讓無坦克牌組因先天傷害分配規則而被過度懲罰。

## 9. 後續實作與驗證

本節是後續工作建議，不是本次程式變更。

- 卡牌資料區分可召喚單位與法術。維持現有 11 個 ID 及 8 格牌組的相容性；新增 ID 後檢查收藏、換牌、存檔、出戰資料及卡牌資訊。
- 能力以可重用的攻擊形狀、命中事件、生命狀態、護盾狀態、傷害類型及施法效果來表示，避免在通用戰鬥流程為每張卡硬寫一套分支。
- 美術使用既有風格化中世紀奇幻厚塗風格；單位以清楚的輪廓與主要色區分；爆擊、破盾、毒素、嗜血、暈眩需有可讀的視覺提示。
- 玩家卡牌資訊優先展示核心定位、一句能力說明及關鍵正式數值；不直接將內部狀態機細節塞入 UI。

| 案例 | 預期 |
| --- | --- |

| 花妖連續命中六次，中途換目標 | 第 3、6 擊爆擊，其餘正常；未命中不計次 |

## 10. 待定事項

- 逐一確認人類兵種的攻擊範圍、增益與治療細節，確保不增加不必要的獨立技能。
- 統一基礎數值、成本、攻擊距離、碰撞與索敵規則。以固定護衛弩手與新手弓手的共用遠程射程為基準之一。
- 確認王子對各法術及反坦克百分比攻擊的傷害比例／上限，並另外確認控制、治療與增益的適用規則。
- 確認中毒跳傷與跨來源刷新、多犀牛暈眩、外來護盾、命中判定等共用規則。
- 實作戰鬥系統後，以等成本牌組與不同陣容實測，不先把示例數值當成正式資料。
- 製作新增六種異獸立繪與三種法術卡圖；本次文件不包含圖檔或戰鬥程式。
